# js-collab-game-2
Second collab
Gra js prosta w uzyciu gra przegladarkowa polecenia do uzycia:
gra.start() — restartuje grę i ustawia stan początkowy.
gra.pomoc() — wyświetla instrukcję
gra.status() — pokazuje aktualny stan gry
gra.mapa() — pokazuje plan pomieszczeń i Twoją pozycję.
gra.rozejrzyj() — rozgląda się po aktualnym pomieszczeniu.
gra.idz("lewo") / gra.idz("prawo") — poruszanie się między pokojami (kosztuje 1 energię).
gra.akcja("karta") — podnoszenie karty dostępu w Recepcji.
gra.akcja("bezpiecznik") — podnoszenie bezpiecznika w Magazynie.
gra.akcja("napraw") — montowanie bezpiecznika w Serwerowni.
gra.akcja("wyjdz") — próba ucieczki przy Wyjściu (wymaga karty i zasilania).
